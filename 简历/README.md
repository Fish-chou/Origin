## 二、浪尖儿社区保卫战 · 坦克大战（附加题）

游戏源码位于 `tank-battle/`。Windows 可双击 `tank-battle/启动游戏.bat`，也可直接打开 `tank-battle/index.html`。

实现内容：

- 玩家移动、发射炮弹
- 敌方坦克 AI、障碍与完整碰撞检测
- 可摧毁砖墙、钢墙、基地防守、装甲生命
- 两波敌军、普通与重装单位、得分和胜负判定
- 标准 / 挑战难度、暂停、重开、全屏和合成音效
- 键盘与移动端触屏操作
- 上传的浪尖儿社区地图底图
- 中央砖墙拼出姓名缩写 `ZZC`

详细操作和结构见 `tank-battle/README.md`。

## 三、目录结构

```text
简历/
├── index.html                   # 个人在线简历入口
├── css/style.css                # 简历样式、响应式、主题、打印
├── js/main.js                   # 简历数据、渲染与交互
├── assets/                      # 证书与项目预览图片
├── tank-battle/                 # 坦克大战完整项目
│   ├── index.html               # 游戏运行入口
│   ├── 启动游戏.bat            # Windows 运行入口

│   ├── js/game.js
│   └── assets/langjian-community.png

```

## 四、部署上线

这是纯静态站点，可将根目录直接上传到 Netlify、Vercel、GitHub Pages 或 Gitee Pages。Netlify 已包含零构建配置，上传后即可访问；获得线上网址后，按赛事平台要求填写并提交。
