# 浪尖儿社区保卫战 · 坦克大战（附加题）

作者：赵梓晨  
技术栈：HTML5 Canvas / CSS / 原生 JavaScript  
运行环境：Microsoft Edge、Google Chrome、Firefox 等现代浏览器

## 直接运行

- Windows：双击 `启动游戏.bat`
- 其他系统：双击或用浏览器打开 `index.html`
- 无需安装依赖，无需联网

## 操作

- 移动：`W A S D` 或方向键
- 射击：`Space` 或 `J`
- 暂停 / 继续：`P`
- 开关音效：`M`
- 手机和平板：使用游戏下方的触屏方向键和射击键

## 游戏规则

保护地图下方中央的浪尖儿社区基地，击退两波敌军。普通敌军承受 1 发炮弹，黄色重装敌军承受 2 发炮弹；基地被击中或玩家装甲归零则失败。第二波开始时，地图中央会出现限时护盾补给。
